# lcy 个人简历与作品集网站 · 完整代码包

本代码包对应当前已部署的网站版本，包含五个独立页面、所有图片、手写字体和原始简历 PDF。

## 打开方法

1. 将压缩包完整解压。
2. 双击 `index.html`，使用 Chrome、Edge 或其他现代浏览器打开。
3. 请保留文件结构，勿单独移动 HTML 文件；无需安装依赖、构建或联网。

如要通过本地服务器预览，并且电脑已安装 Python，可在本目录打开终端，运行：

```bash
python -m http.server 8000
```

然后访问 http://localhost:8000 。停止时按 Ctrl+C。

## 页面与文件

- `index.html`：首页、四张图片卡片、下载简历和底部联系方式。
- `about.html`：关于我；10% 白色半透明内容框，教育与能力、竞赛与校园经历上下分页。
- `projects.html`：研究项目与详情弹窗。
- `experience.html`：实习经历、类别筛选和半透明卡片。
- `contact.html`：联系方式页。
- `style.css`：基础样式与打印样式。
- `landing.css`：当前天空蓝主题、导航、卡片和各页面的最终样式。
- `script.js`：项目详情、筛选、复制联系信息与打印。
- `orbit.js`：首页卡片点击、拖动、前后换位、方向键与自动轮播。
- `about-pages.js`：关于我页面上下翻页和页码状态。
- `assets/`：四张卡片图片、原始 PDF、手写字体及字体授权说明。

## 修改内容

用 VS Code 或任意文本编辑器打开文件夹。页面文字、照片路径和联系方式在相应 HTML 中修改；项目弹窗正文在 `script.js` 的 `projectData` 中修改；主题样式在 `landing.css` 中调整。

更换下载简历时，用新 PDF 覆盖 `assets/resume.pdf`。目前该文件与最初上传的简历 PDF 内容完全一致。

首页左上角使用内嵌手写字体显示 `lcy`。首页底部联系电话和邮箱点击后复制并显示提示；部分浏览器会限制本地文件的剪贴板权限，代码含兼容复制处理，必要时可使用上述本地服务器。

## 部署

这是纯静态多页面网站，可将本文件夹内全部文件上传到静态网站托管服务，确保根目录为 `index.html` 所在目录。包内不含当前托管项目身份、Git 元数据或凭据。原托管页面的访问权限不会随 ZIP 自动迁移，自行托管时由新平台设置。
